## 6. Général

**Produits uniques vs Ménagère et sets** : la matrice distingue une référence = un seul type de
produit (ex. une fourchette unique, un set de 4 steaks identiques) vs une référence = plusieurs
types de produits différents (ex. ménagère couteaux+fourchettes+cuillères+cafés, ou set de
couteaux chef/office/santoku).

**Circuit produit existant** : suggestion d'appro validée (Eric+David) → recherche info si
dernier achat avant 2023 → création fiche achat → demande prix fournisseur → vérification
artwork (Clarisse) → commande Sylob → MAJ fiche achat (n° commande + n° lot) → retour prix →
ajout prix commande Sylob → artwork validé reçu → MAJ fiche (version artwork validé) →
signature (Marlène + Eric) → envoi commande + fiche → fiche re-modifiée en cours de commande
(dimensions marquage, pantone manche, dimensions couvert).

**Circuit nouveau produit** : demande Eric → recherche info (souvent vague au départ) →
demande création artwork (Clarisse, si applicable) → demande création référence (Emmanuelle) →
référence créée → commande Sylob → fiche achat → envoi commande + fiche → nouvel artwork
validé/envoyé (Clarisse) → MAJ + renvoi fiche → fiche re-modifiée en cours de commande.

**Pièges récurrents** :
- La direction utilise parfois un nom de produit obsolète (ex. Eric dit "INTUITION" pour les
  "ACIDULE" actuels) ou un nom vague pour un nouveau produit (ex. "Nouveau Laguiole
  Heritage") — confusion possible faute de référence citée.
- **Noms de fournisseur historiques toujours utilisés par la direction** — correspondance
  confirmée (déjà intégrée dans `ALIAS_CONNUS`, `src/scripts/etl/enrich_ca.py`) :
  - POLLYDA + DIAMOND TRACK = GUANGWEI
  - HUGUESUN + SMART IRON = JIT GLOBAL
  - HIAMEA = AOYAM
  - VICO = MINGHAO
